# 界面文案

四个文件对应该工具的四种界面语言：

- `zh-Hans.txt` 简体中文
- `zh-Hant.txt` 繁体中文
- `en.txt` 英文
- `ja.txt` 日文

改句子时只改这些文件，然后重新执行 `make install`。命令名保持英文，例如 `switch`、`save`、`rename`。

## 格式

一个键占一行，方括号里是键名。下一行起直到下一个键，是这句话。键和键之间空一行。

```
[saved]
已保存 %1  %2

[help]
第一行

空行会保留。
```

- 键名必须和 `Sources/AgyAccount/Localization.swift` 里的 `TextKey` 完全一致。四个文件都要有同一套键，不能多，也不能少。
- `%1`、`%2`、`%3` 是运行时填进去的名字或邮箱。同一句话在四种语言里要使用同一组记号，数字不要改。
- 行首和行尾的空格会保留。
- 单独成行、而且整行只有 `[键名]` 的文字会被当成新的一句。正文里不要写这样的一行。
- 这些文件里不要写登录内容或 token。

语言列表里显示的自称（简体中文、English、日本語）在 `AppLanguage.nativeName`，不在这四个文件里。
