[help]
Switch between Antigravity CLI accounts.

Usage
  agy-cs
  agy-cs <command>
  agy-cs colab <command>

Commands
  current                      Show the recorded email. This does not open the keychain
  list, ls                     List saved accounts with the plan and quota recorded at the last switch. This is the default command
  save <name>                  Save the current keychain login under a name
  save <name> --force          Replace another login that is already saved under that name
  switch                       Choose in the terminal. Item 1 is the current account and cannot be selected; item 2 adds an account; later items are saved accounts. agy then starts
  switch add                   Add an account directly, without the menu. The current login is kept, then agy opens
  switch <name>                Switch to a saved account
  next                         Switch to the next saved account
  refresh quota                Look up the plan and quota of every saved account again, then list them
  rename <new>                 Rename the current account. This does not open the keychain
  rename <old> <new>           Rename account old to new. This does not open the keychain
  move <name> <position>       Move an account to that position in the list. 1 is the top
  rm <name>                    Delete a saved copy. The keychain login stays
  rm <name> --force            Delete the only remaining copy of the recorded login
  guard                        Show whether old-session keychain write-back blocking is on
  guard on / off               Enable or disable blocking old-session write-backs
  stats [options]              Show local Antigravity usage overview, heatmap, and model health timeline
  session [<id>] [options]     Show session context window breakdown and live token speed telemetry
  statusbar [on|off]           Enable or disable live context and speed in the menu bar
  language, lg                 Show the current language
  language <code>, lg <code>   Change the language
  help                         Show every command and what it does

help, -h, and --help show this text.
With no language chosen, agy-cs follows the system language. Codes: zh-Hans 简体中文, zh-Hant 繁體中文, en English, ja 日本語.
On the first run, when no account is recorded yet, agy-cs reads the keychain once and saves the current login under the characters before @.
After that, current, list, rm, rename, move, language, and help read only the non-secret records in ~/.agy-cs/.
save, switch, next, and that first-run initialization read the keychain. Secret copies stay in ~/.gemini/antigravity-cli/accounts/.
After a switch, next, or a new account, a separate background process asks Google for each account's plan and quota and records them in ~/.agy-cs/usage/. The switch does not wait for it and is not affected by it.
list only shows those records and makes no request. A quota whose reset time has passed is shown as 100%. refresh quota asks right away and does not read the keychain.
Only switch without a name, and switch add, start agy in this terminal. Adding an account keeps the current login first, then opens agy. If you quit before a new email is stored, the previous login is restored.
Prefix commands with colab to switch google-colab-cli accounts (for example, agy-cs colab ls, agy-cs colab switch <name>, agy-cs colab refresh quota). Secret copies stay in ~/.config/colab-cli/accounts/, and non-secret records and quota cache stay in ~/.agy-cs/colab/. colab switch add opens a browser to sign in and finishes by itself, without a terminal.
