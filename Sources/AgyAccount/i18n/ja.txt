[help]
Antigravity CLI のアカウントを切り替えます。

使い方
  agy-cs
  agy-cs <コマンド>
  agy-cs colab <コマンド>

コマンド
  current                      記録されているメールアドレスを表示します。キーチェーンは開きません
  list, ls                     保存したアカウントと、前回の切り替え時に記録したプランと利用枠を表示します。コマンドを省略したときもこれです
  save <名前>                  現在のキーチェーンログインを名前を付けて保存します
  save <名前> --force          その名前に別のログインが保存されているとき、確認して置き換えます
  switch                       端末で選びます。1 は現在のアカウントで選べません。2 は新しいアカウントです。3 以降は保存済みです。完了後に agy を起動します
  switch add                   選択せずにアカウントを追加します。現在のログインを保存してから agy を開きます
  switch <名前>                保存したアカウントに切り替えます
  next                         次の保存済みアカウントに切り替えます
  refresh quota                保存済みの全アカウントのプランと利用枠を問い合わせ直し、一覧を表示します
  rename <新しい名前>          現在のアカウントの名前を変えます。キーチェーンは開きません
  rename <古い名前> <新しい名前>  アカウントの古い名前を新しい名前に変えます。キーチェーンは開きません
  move <名前> <位置>           アカウントを一覧のその位置に移します。1 が先頭です
  rm <名前>                    保存したコピーを削除します。キーチェーンのログインは変えません
  rm <名前> --force            記録中のログインがこのコピーだけのとき、確認して削除します
  guard                        旧セッションの書き戻し防止が有効か表示します
  guard on / off               旧セッションによるキーチェーン書き戻し防止を切り替えます
  language, lg                 現在の言語を表示します
  language <コード>, lg <コード>  言語を切り替えます
  help                         すべてのコマンドと機能を表示します

help、-h、--help はこの説明を表示します。
言語を指定しないときはシステムの言語に従います。コード: zh-Hans 简体中文、zh-Hant 繁體中文、en English、ja 日本語。
初回起動でアカウント記録がまだないとき、キーチェーンを一度読み、メールアドレスの @ より前の文字で現在のログインを保存します。
その後、current、list、rm、rename、move、language、help は ~/.agy-cs/ の秘密ではない記録だけを読みます。
save、switch、next、およびこの初回初期化だけがキーチェーンを読みます。秘密のコピーは ~/.gemini/antigravity-cli/accounts/ に残します。
switch、next、アカウントの追加が成功すると、別のバックグラウンドプロセスが各アカウントのプランと利用枠を Google に問い合わせ、~/.agy-cs/usage/ に記録します。切り替えはそれを待たず、影響も受けません。
list はその記録だけを表示し、通信しません。リセット時刻を過ぎた利用枠は 100% と表示します。refresh quota はすぐに問い合わせ、キーチェーンは読みません。
名前なしの switch と switch add だけが、この端末で agy を起動します。新しいアカウントは現在のログインを先に保存してから agy を開きます。新しいメールアドレスが保存される前に終了したときは、元のログインを戻します。
colab を前に付けると google-colab-cli のアカウントを切り替えられます（例: agy-cs colab ls、agy-cs colab switch <名前>、agy-cs colab refresh quota）。秘密のコピーは ~/.config/colab-cli/accounts/ に、秘密ではない記録と利用枠キャッシュは ~/.agy-cs/colab/ に保存します。colab switch add はブラウザでログインし、許可すると自動で完了します。ターミナルは開きません。
